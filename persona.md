# CampusFind — User Personas

Illustrative personas for planning; names and situations are fictional.
For example:

# 1. Linh — Student who lost an item

| Aspect | Description |
| --- | --- |
| Personal | 21-year-old international student who often studies at the campus library. |
| Job / daily activities | Attends classes and moves between the library, cafeteria and lecture rooms. |
| Education / technical comfort | Undergraduate; comfortable with mobile apps, but finds long Korean group-chat threads difficult to follow. |
| Relevance | Needs one searchable place to check whether someone has found her belongings. |

**Situation:** Linh notices her wallet is missing after leaving the library. She does not know which campus chat group to check.

**User story:** As a student who lost an item, I want to search found reports by keyword and location so that I can quickly identify a possible match.

# 2. Minjun — Student who found an item

| Aspect | Description |
| --- | --- |
| Personal | 22-year-old student with a busy class and club schedule. |
| Job / daily activities | Attends lectures, meets classmates and participates in club activities. |
| Education / technical comfort | Undergraduate; uses his phone frequently and prefers short, straightforward forms. |
| Relevance | Wants to help return an item without posting the same message in several groups. |

**Situation:** Minjun finds a pair of earphones in a classroom and has only a few minutes before his next lecture.

**User story:** As a student who found an item, I want to post its description, location and photo in a short form so that its owner can find the report and contact me.

# 3. Jiyoung — Campus office staff member

| Aspect | Description |
| --- | --- |
| Personal | 38-year-old staff member at a campus office that receives lost belongings. |
| Job / daily activities | Answers student questions, stores handed-in items and helps students collect them. |
| Education / technical comfort | College graduate; comfortable with email and spreadsheets, prefers clear labels and simple controls. |
| Relevance | Needs to show which items are still waiting for collection and avoid repeated inquiries about returned items. |

**Situation:** A student collects a previously reported umbrella, but other students continue asking whether it is available.

**User story:** As a staff member handling lost belongings, I want to mark a report as recovered after returning the item so that students can see that the case is closed.
